# 一次性设备测试

网页点击“此设备测试”，选择节点、设备名和城市（可选），点击“生成并复制测试命令”。在要测试的 Mac / Windows / Linux 终端粘贴并回车即可，无需下载文件或切换目录。浏览器不执行原生网络探测。命令自动获取本轮程序，核对 SHA-256 后在内存执行，结果上传到网站。复制失败时可点“复制测试命令”重试，或选中命令框手动复制。

- Mac/Linux：已有 Python 3 和系统 ping。Linux 还需要 ip 命令和网卡绑定权限。脚本不会安装依赖或请求提权，条件不满足就停止。
- Windows：Windows PowerShell + NetTCPIP 模块。调用原生 ICMP；每个包之前检查路由。存在活动非物理网卡、路由不明确或路由变化时停止。不会修改执行策略。
- iPhone/Android 不支持执行这些桌面脚本。
- 每个目标 3 个 Ping；可选线路探测最多 30 跳，每跳 1 包。顺序执行，Ctrl+C 取消；结果上传失败会明确报错，没有后台重试。
- Mac 使用 IP_BOUND_IF / ping -b；Linux 使用 SO_BINDTODEVICE / ping -I；系统 ping 不支持 -I 时，使用绑定网卡的原生 ICMP 套接字（需要已有权限），发送前核对物理网卡和目标路由。只使用固定公网 IPv4，不通过代理域名解析。任何失败不回退到普通未绑定测试。
- Windows 使用物理路由检查，检测到 VPN/TUN 虚拟接口时拒绝测试，需要用户自行决定是否退出相关软件。本工具不会替用户关闭 VPN。
- 上述校验是操作系统出口校验，不能证明运营商侧或第三方内核过滤驱动完全没有转发流量。后台将其标为“设备报告”，不宣称服务器独立验证了设备状态。
- 不安装、不驻留，不改代理、路由、防火墙、开机项；不创建输出文件。默认命令不写脚本文件。可选手动下载才会留下文件，可自行删除。终端历史可能保存含短期令牌的命令，本工具不会改写终端历史。运行时会产生少量探测流量；不能承诺零资源占用。

## 任务和权限

管理员通过 POST /api/device-tests 创建任务；脚本内容内含一小时有效的随机任务令牌（仅允许获取本轮脚本及提交本轮结果）。服务端只保留令牌摘要（内存，服务重启后需重建任务）。脚本不含 ADMIN_TOKEN、VPS 密码、SSH 密钥或任意远程命令。

POST /api/device-tests/script 校验任务令牌，返回创建任务时固定的程序；拒绝过期或已提交任务。令牌放在 POST 正文，禁止 URL 查询参数携带令牌。命令获取程序时禁用 HTTP 代理和重定向，保留 TLS 证书验证，并使用创建任务时给出的 SHA-256 检查内容。获取程序和上传属于控制请求，不计入网络延迟；原生测试继续绑定物理网卡。

POST /api/device-tests/upload 只校验任务令牌，严格限制目标、结果数和样本格式，成功提交后令牌不能重用；最多 30 个未过期待执行任务。此端点不得注入管理令牌或开放其他管理 API。Nginx 仅对上述 script、upload 两个精确路径关闭 Basic Auth，并限制 POST / 1 MB 请求体，其他路径仍需登录。

任务创建不会发包。设备结果独立保存在 db.deviceRuns，最多 50 轮；不会覆盖后台服务器的测量。从设备记录可切换地图起点，地图只采用该设备最新一轮结果。设备名用于识别，由用户填写；每个浏览器以随机 ID 关联设备，清理浏览器数据后会成为新设备。

## VPS 互测

“后台测量 → 全部 VPS 互相 Ping 一轮”维持现有实现。本机脚本只负责当前电脑到公网 VPS；没有独立公网 IP 的 frp 设备明确跳过，不能拿 frps 的 Ping 结果冒充 frpc。VPS 之间的 SSH 操作由部署主机发起，不依赖电脑的代理或脚本。

## 验证

npm test；python3 -B tests/device-script.test.py；npm run build。Mac/Linux 需要实际网卡环境验证。Windows 分支必须在 Windows 上单独验证，不以代码审阅代替真实系统验证。


## 命令启动器

Mac/Linux 使用已有 Python 3。Windows 使用无 Profile 的临时 PowerShell 子进程；不设置 ExecutionPolicy Bypass，不更改执行策略。组织策略限制执行时停止。Windows 尚未实机验证。下载脚本保留在折叠的可选项中。

## 配置与测量起点（0.4.0）

- 此设备保存自己的节点范围、物理网卡、系统、位置与线路开关；不修改后台自动调度。首次范围沿用后台配置。节点方法及公网入口共用连接档案，可在此设备面板打开“连接配置”。
- 支持原生 Ping、TCP 建连、SSH banner 后端响应。只有 ICMP 结果称为 Ping；只有 TCP 入口成功不能标成 frpc 可达。无独立 IP 的 frp 节点可通过已配置入口测 SSH banner，不再直接跳过。
- 延迟和纯线路轮次分开保存。单独分析线路不会清空最近一轮延迟。
- VPS 互测、SSH 登录测中转段及 VLESS 仍由后台执行，不向一次性脚本下发密码或密钥。此设备面板提供后台配置入口，不把这些结果改成本机来源。
- 当前仍保持单次退出，不开启本机定时任务。关闭本机终端后无法继续从该设备探测；网页不会替代它发包。
- 地球、平面、线路均有“测量起点”下拉框：当前设备、其他已上报设备、部署主机及各 VPS。切换只改变显示，不启动测试。当前浏览器生成的任务回传后自动切换到该设备（关闭弹窗后仍有效）。
- 未测节点不补后台延迟。VPS 作为起点时，列表、统计与地图使用它发出的结果。设备没有位置时可点“设置起点位置”，不修改部署主机坐标。
